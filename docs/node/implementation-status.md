## 已接入的业务行为

| 组别             | 已实现内容                                                                                                                                                                                                                                                                                          |
| ---------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 权限与会话       | 团队成员默认可创建、读取、编辑和生成；显式 `editor/viewer/none` 即时覆盖项目默认权限，删除和团队管理限所有者或管理员。成员移除、账号切换与 refresh 轮换撤销旧会话，通过 Redis 通知其他实例关闭旧 WS。协作 presence、锁和版本补发使用 Redis 与持久画布版本。                                         |
| 项目、素材、剧本 | 个人项目与剧本复制导入，复制后的媒体登记重新归属目标账号；原件保留。项目和剧本版本、步骤、回收站、30 天自动清理及子项目保护，素材、主体、节点、目录、资产分页和引用检查。上传登记校验前端媒体元数据和上传者路径，但缺少 OSS 对象验真能力时返回 503。                                                |
| 创作与协作       | 场景工具、声音、提示词、模型和风格目录路由完成输入与权限校验；可由持久目录提供的列表及编辑接口读取真实记录。已有稳定 `request_id` 的生成任务经能力校验、事务扣费、outbox 和 worker；积分来源顺序实际控制扣费桶，取消或失败按原来源退款。缺供应商或价格的旧付费入口返回 503。                        |
| 公开内容与账务   | 作品发布先校验项目、画布、媒体归属；公开列表、详情、收藏、删除与受 `allow_clone` 限制的复制。活动报名、草稿、投稿、通知、文章、团队额度和统计读取持久记录。套餐与充值价格只读服务端配置；订单、空间账单和已开票记录按账号隔离。支付下单、价格折算及开票提交缺配置时返回 503，不创建假支付或假发票。 |

## 外部依赖与配置缺口

- 真实 OSS STS、对象验真和上传登记、节点下载签名，需要 OSS 配置；当前不会接受未经验证的媒体登记。
- 公共资产、图片场景和打光预设从已发布目录读取；目前没有官方素材或预设种子，需由运营导入可信内容后才会展示条目。
- 场景、剧本生成/询价、工作流、音色克隆、提示词翻译、火山素材和模型目录依赖供应商及价格数据，缺失时明确返回 503。开发模拟仅在 `DEV_MOCK_EXTERNALS=true` 时运行，生产配置禁止开启。
- 套餐、积分充值及空间价格表为服务端目录，目前没有产品定价数据；空目录返回 503。空间配额须由有效权益配置提供。支付商户签名资料、回调协议、续费/升级折算与开票服务尚未提供；因此支付回调及实际权益发放没有接入。现有订单和发票记录可以按权限查询，客户端请求不能改变支付状态。
- 真实第三方沙箱验收、跨实例断线压力测试和 Nuxt 浏览器逐接口联调尚未完成；不能把路由覆盖视为生产验收。

## 契约差异记录

- 原规格的接口数字与当前源码不一致；按前端 `api/` 实际静态请求去重为 196 个操作，快照保留每个调用来源。
- `POST /drama` 需要前端传来的 `parent_id,is_group` 并返回首张画布 ID；项目列表还使用 `parent_id,name,all` 和项目组字段。项目及剧本回收站的请求/响应已按前端类型对齐。
- `/scene/*` 与旧 `/script/*` 付费入口没有稳定 `request_id`，无法在响应丢失后可靠识别重试。生产缺供应商与定价时返回 503；若将来接入真实收费服务，需先补齐可查询的幂等意图协议。
- 前端 OSS 对象键以用户 UUID 为前缀，团队账号仍共享该上传者前缀。仅凭 URL 或对象键无法证明账号下对象已上传，必须由 STS 授权记录和 OSS 对象元数据共同验证后才能开放登记。

原规格的上线验收清单见[后端生成规格](backend-generation-spec.md)。
