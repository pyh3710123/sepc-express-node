# 画布图片档位加载

本次前端调整保留 100 / 200 / 400 / 800 / 1600w WebP 档位，按节点显示宽度、画布缩放和 DPR 选档。业务原图 URL、节点坐标、连线端点及保存通道继续沿用现有协议。

## 请求与缓存

- 初次进入视口直接使用目标档；已有小档缓存时先显示缓存并请求目标档，已有足够清晰的缓存时直接复用。
- 平移、缩放手势期间保留当前画面；缩放停稳 150ms 后请求最终档位，取消过期预热。缩小时复用已加载的大档，或直接切到已缓存的小档，不为缩小新增下载。
- 可见 DOM 图片与离屏预热共享 6 个并发位；可见请求优先。等待中的任务不提前创建离屏 Image，失效订阅和离开视口的未完成 DOM 请求会取消。
- 保留现有视口及缓冲区挂载范围。DOM 池最多缓存 512 项，解码像素预算为 32 × 1024 × 1024；超预算优先回收离屏大图，使用中的图片受到保护。像素预算按 RGBA 约合 128MiB，仅用于缓存淘汰，不是浏览器总内存硬上限。
- 停车层继续执行空闲回收；最后一个画布销毁时清除 DOM、监听、等待任务和媒体缓存。

## 高清预览与后端约定

现有 `GenerationMediaOutput` 已声明 `url`、`preview_url`、`cover_url`、`width`、`height`。前端现在消费这些字段，无需新增生成接口：

```json
{
  "outputs": {
    "images": [{
      "url": "https://资源域名/高清原图.png",
      "preview_url": "https://资源域名/轻量预览.webp",
      "width": 4096,
      "height": 6144
    }]
  }
}
```

`preview_url` 应指向与原图内容、比例一致的独立轻量文件，并可供浏览器访问。若需要继续使用 OSS 五档转换，文件应位于已有支持的资源域名，且满足图片处理限制。`width`、`height` 必须为原图尺寸。没有转换能力的预览文件直接显示；处理后预览失败先回退预览文件，再回退原图。

前端将元数据按原图 URL 保存在节点 `extra_data.imageResultMetadata` 中，生成结果 `url/urls/assetUrl` 继续保存原图。多图切换按 URL 查找，保存时只保留当前结果的映射。服务端已返回原始宽高时不再探测尺寸；有独立预览但尺寸缺失时，仅尝试轻量元数据接口，失败后保留已有画幅。

本仓库只包含前端和代理层，未实现生成服务的预览文件产出。后端未返回独立预览时，继续使用现有原图档位与失败回退，因此旧高清资源仍可能回退下载原图。
